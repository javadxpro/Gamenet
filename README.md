# 🎮 Gamenet — فروشگاه گیم نت

سایت فروشگاهی گیم‌نت: فروش بازی کپی‌خور (PS4/PS5 و Xbox)، گیفت‌کارت، اشتراک‌ها و سکه و جم.
سایت کاملاً **استاتیک** است (بدون بک‌اند) و روی **GitHub Pages** منتشر می‌شود:

> 🌐 https://javadxpro.github.io/Gamenet/

## 🚀 اجرای محلی

```bash
python3 -m http.server 8000
# یا
npx serve .
```

سپس `http://localhost:8000` را باز کنید.

## 📄 صفحات

| صفحه | توضیح |
|---|---|
| `web.html` | صفحه رسمی / لندینگ با صحنه سه‌بعدی WebGL (three.js) |
| `WebPC.html` | نمایش گرافیک فراکهکشانی با انتخاب کیفیت |
| `index.html` | صفحه اصلی فروشگاه (بازی‌ها + اشتراک‌ها) |
| `games.html` | فهرست کامل بازی‌ها |
| `game1/2/3.html` | جزئیات بازی‌ها و افزودن به سبد |
| `cart.html` | سبد خرید، ثبت سفارش و کد پیگیری |
| `giftcard.html` | فروشگاه گیفت‌کارت |
| `subscriptions.html` | اشتراک‌ها و سکه و جم |
| `offers.html` | پیشنهادها |
| `shop.html` | فروش بازی |
| `news.html` | اخبار |
| `team.html` / `team-info.html` / `analysis.html` | تیم فوتبال راه ابریشم (ترکیب، وضعیت، آنالیز) |
| `404.html` | صفحه خطای ۴۰۴ |

## 🗂 ساختار

```
Gamenet/
├── *.html               # صفحات سایت
├── Webstyle.css         # استایل اصلی
├── script.js            # اسکریپت مشترک (سبد خرید، ثبت سفارش، منو، افکت‌ها)
├── WebGL.js             # صحنه سه‌بعدی three.js (صفحه web.html)
├── images/              # تصاویر بازی‌ها (آفلاین در خود سایت)
├── assets/audio/        # موزیک زمینه web.html
├── favicon.svg
├── robots.txt / sitemap.xml
├── scripts/             # ابزار توسعه
│   ├── check-links.mjs  # بررسی لینک‌های داخلی
│   └── inject-head.mjs  # (یک‌بار مصرف) تزریق meta/OG
└── .github/workflows/ci.yml
```

## ⚙️ CI

روی هر push / PR:
- `node --check` روی همه فایل‌های JS
- `node scripts/check-links.mjs` برای اطمینان از اینکه هیچ href/src داخلی به فایل غیاب اشاره نکند

## 🛒 نحوه ثبت سفارش (اکنون)

1. کاربر در صفحه اصلی «ثبت‌نام» می‌کند (فقط `localStorage`، بدون بک‌اند).
2. اقلام به سبد می‌رود و با «ثبت سفارش» یک **کد پیگیری** تولید و کپی می‌شود.
3. کاربر کد را از طریق شماره‌های تماس به مدیریت می‌دهد.

> ⚠️ احراز هویت، ثبت سفارش و پرداخت هنوز سمت کاربر است. افزودن بک‌اند/ربات تلگرام برای ثبت واقعی سفارش در roadmap است.
